Paper tape reader

Paste a program or choose a file (you can also drop one on the page). The reader types it at 10 characters per second (Turbo: faster), as if you typed it. With a file name it saves the program: it starts ed for you and writes the file (a file of that name is replaced). As on the keyboard, # erases a character and @ the whole line.
